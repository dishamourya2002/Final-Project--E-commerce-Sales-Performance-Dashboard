# E-Commerce Sales Dashboard

## Project Overview
This project presents an interactive E-Commerce Sales Dashboard built using Tableau. The dashboard analyzes sales performance, customer activity, product categories, payment methods, and order status using the Brazilian Olist E-Commerce dataset.

The objective of this project is to transform raw data into meaningful business insights through data cleaning, relationships, KPI creation, and interactive visualizations.

## Dataset
**Dataset Used:
** Olist Brazilian E-Commerce Dataset

Files used:
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_products_dataset.csv
- product_category_name_translation.csv
- olist_customers_dataset.csv
- olist_order_payments_dataset.csv


## Tools Used
- Tableau
- Microsoft Excel
- GitHub


## Dashboard KPIs
- Total Orders
- Total Customers
- Total Revenue
- Average Order Value


## Visualizations
- Monthly Sales Trend
- Top 10 Product Categories
- Order Status Distribution
- Payment Type Distribution


## Data Cleaning
- Checked Duplicate Records
- Checked Missing Values
- Established Relationships Between Tables
- Verified Data Consistency


## Table Relationships
- Orders ? Customers (Customer ID)
- Orders ? Order Items (Order ID)
- Order Items ? Products (Product ID)
- Products ? Product Category Translation (Product Category Name)
- Orders ? Payments (Order ID)


## Key Insights
- Credit Card is the most frequently used payment method.
- Delivered orders represent the highest number of completed orders.
- Health & Beauty is the top-performing product category.
- Sales increased steadily over time before declining in the final available period.
